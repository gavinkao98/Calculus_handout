規範 02  /  數學排版
數學行裡什麼可以出現，什麼不行
現行系統把數學（Latin Modern via pdflatex）與散文（IBM Plex Sans）接在同一行，沒有規則決定誰贏——實測幀裡同一個註解欄出現過三種處理。以下五條把它收成一套。
規則 1
數學行內不得混入散文
說明一律離開數學行，進右側註解 rail。
現況 0 ≤ |sin θ| ≤ |θ| (chord ≤ arc)
改 0 ≤ |sin θ| ≤ |θ| CHORD ≤ ARC
規則 2
註解 rail 只有兩種語域
整段數學，或整段 sans 小型大寫。不混。
現況 sum-to-product A = x + h,  B = x write h = 2 · h/2 ＝同一欄三種處理
改 SUM-TO-PRODUCT A = x + h,  B = x h = 2 · h2 ＝說明用 sans caps，代換用數學
規則 3
正斜體照數學慣例，不照視覺喜好
變數斜體；運算元、函數名、數字正體。
sin θ lim h→0 f′(x) max sin θθ 正體：sin cos lim max log 與所有數字
規則 4
證畢記號是字形，不是元件
現況 讀起來像按鈕
改 ■ 與該行同色同大小
而且分頁證明的第 1 頁不放 ∎——改放 STEP 1 OF 2，∎ 留到真正收尾。
